# Cloud-Based Static Website Deployment

## Project Overview

This project demonstrates the development and deployment of a responsive static portfolio website using HTML, CSS, and JavaScript. The website is hosted using GitHub Pages, providing publicly accessible hosting over HTTPS.

**Live Website:** https://sapnaahamed23-hub.github.io/cognevance_static-website-deployment/

**GitHub Repository:** https://github.com/sapnaahamed23-hub/cognevance_static-website-deployment

## Objectives

- Develop a responsive static website.
- Use Git and GitHub for source code management.
- Deploy a website using cloud-based static hosting.
- Understand the workflow from development to deployment.

- Evaluate website performance and document results.

## Deployment Workflow

1. Developed the website using HTML, CSS, and JavaScript.
2. Organized the source files in a local project directory.
3. Created a GitHub repository and uploaded the project files.
4. Opened repository Settings and navigated to Pages.
5. Selected **Deploy from a branch**, using the `main` branch and `/ (root)` directory.
6. Saved the configuration and allowed GitHub Pages to publish the website.
7. Opened the published website in a browser to verify its availability and appearance.

## Hosting Configuration

- **Hosting platform:** GitHub Pages
- **Deployment source:** `main` branch
- **Published directory:** Repository root (`/`)
- **Build process:** Static files served directly without a separate build step.
- **Security:** HTTPS enabled through GitHub Pages.

## Testing and Monitoring
