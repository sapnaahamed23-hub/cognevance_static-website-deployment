
# Cloud-Based Static Website Deployment

## Project Overview

This project demonstrates the development and deployment of a responsive personal portfolio website using HTML, CSS, and JavaScript. The website is hosted using GitHub Pages.

**Live Website:** https://sapnaahamed23-hub.github.io/cognevance_static-website-deployment/

## Objectives

- Develop a responsive static website.
- Use GitHub for source code management.
- Deploy a website using a cloud-based hosting service.
- Understand the workflow from code creation to deployment.
- Document the deployment process and configuration.

## Technologies Used

- **HTML5:** Website structure and content

## Deployment Workflow

1. Created the website using HTML, CSS, and JavaScript.
2. Saved the source files locally.
3. Uploaded the files to a GitHub repository.
4. Opened the repository's Settings and navigated to Pages.
5. Selected **Deploy from a branch**, branch `main`, and folder `/ (root)`.
6. Saved the configuration and waited for GitHub Pages to publish the website.
7. Verified the published website in a browser.

## Hosting Configuration

- **Hosting platform:** GitHub Pages
- **Deployment source:** `main` branch
- **Published directory:** Repository root (`/`)
- **Build process:** Static files served directly without a separate build step

## Security Considerations

- No passwords, API keys, or private credentials are required by the website.
- The external GitHub link uses `rel="noopener noreferrer"` with a new browser tab.
- HTTPS is provided through the GitHub Pages website URL.
- Only publish information intended to be public.
